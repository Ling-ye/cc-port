# 使用受管远端镜像，而不是可编辑工作区

CC Port 将远端资源仓库作为跨设备事实源，在本机持久维护隐藏、可重建的受管远端镜像，并从指定 commit 生成只读远端快照。受管镜像只服务于清单读取、比较和安全计划；AI 工具继续使用各自的原生目录作为本地实例，桌面主流程不创建或暴露用户需要维护的 Git 工作区。

## Considered Options

- 拒绝可编辑中枢：它会在远端事实源和 AI 工具原生目录之间引入第三份可修改状态，重新产生 dirty、ahead、diverged、分支和合并冲突语义。
- 拒绝每次操作临时克隆：它会重复认证、网络传输和对象下载，无法稳定提供离线缓存视图，也不利于以 commit 为边界复用比较结果。

## Consequences

“刷新远端”只更新受管镜像和远端快照；“扫描本地”只观察 AI 工具原生目录；安装与上传必须从选中资源生成计划后分别写入本地实例或远端资源仓库。旧 `resource_pull`、用户配置的本地工作区和仓库级一键更新不进入新的桌面工作流，仅保留兼容能力。
