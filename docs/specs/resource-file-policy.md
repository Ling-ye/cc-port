# 资源文件安全策略规格

## 目标

扫描、采集、导入、复制、哈希、快照和部署使用同一套文件筛选规则，防止敏感数据和冗余产物进入资源仓库或目标工具目录。

## 排除规则

- 排除 `.git`、虚拟环境、缓存、依赖目录、构建目录和临时目录。
- 排除二进制发布物、压缩包、日志、锁文件和 Python 字节码。
- 排除 `.env` 及 `.env.*`，但允许 `.env.example`、`.env.sample`、`.env.template`。
- 排除符号链接，禁止通过链接读取资源根目录外的内容。
- 清单中声明的路径仍必须经过相同安全策略，清单不能绕过排除规则。

## 敏感内容

- 文本采集继续对 token、API key、密码和私钥模式进行脱敏或阻断。
- MCP `env` 只保存 `${NAME}` 占位符。
- 被排除文件不参与资源签名和差异判断。

## 验收标准

- 所有导入与采集入口均不保存真实 `.env` 文件。
- 模板环境文件正常保存。
- 同一目录在采集、复制和签名阶段得到一致的文件集合。
- 符号链接不能把仓库外文件带入资源。
