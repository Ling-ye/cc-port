# 资源平台兼容性规格

## 目标

同一资源的扫描、安装计划、安装、环境部署、预览和导出必须使用同一套平台兼容性判断。

## 规则

- `RegistryItem.platforms` 是可选平台白名单；空列表表示允许所有已启用平台。
- 非空白名单只允许名称完全匹配的平台。
- 显式选择不允许的平台时，计划返回阻断原因，执行不得写入缓存或目标目录。
- 平台被移出白名单后，已经存在的安装仍显示为“遗留安装”，允许用户显式卸载，但不得继续更新。
- 未知平台名称可以保存在 registry 中，但只有配置并启用同名平台后才可能产生目标。
- Claude 插件导出只包含 active、local、允许 `claude-code` 且存在 `SKILL.md` 的 skill。

## 验收标准

- Cursor-only 资源不会出现在 Codex 的安装或环境部署计划中。
- 对不允许平台执行安装不会创建缓存、目标文件或管理标记。
- 遗留安装在资源清单中可见且可卸载。
